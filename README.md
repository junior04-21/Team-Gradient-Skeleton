# Agile E-Commerce Team Project (Gradient Tech Ltd)

A desktop PC sales and e-commerce system built by a four-person Agile team as part of the Agile Development Team Project module at De Montfort University (2026).

## My role
I owned the **Customer Management** component. The rest of the team owned Order Processing, Stock Management and Staff Management.

## What I worked on
- Designed the customer database table and built the Customer Management pages
- Refactored the pages to use a Bootstrap grid layout instead of fixed positioning
- Fixed bugs, including broken redirects and incorrect blank-checks
- Added front-end input validation and page navigation
- Wrote unit tests, stored procedures and a customer collection class
- Contributed to team documents: use case diagram, risk register, ethics checklist, Scrum meeting minutes and weekly journal entries

## Tools and technologies
C#, ASP.NET Web Forms, SQL Server, Bootstrap, Visual Studio, Git and GitHub

## Architecture
Three-tier architecture: presentation, business logic and data layers.

## How to run
1. Install Visual Studio with the ASP.NET workload.
2. Clone this repository and open the `.sln` file.
3. Set up the SQL Server database, then press Start.

## What I learned
Working in a Scrum team, sharing a codebase through Git, test-driven development, and building a database-backed web application in layers.
